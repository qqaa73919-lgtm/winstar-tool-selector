# WINSTAR V4 保證有刀連動版

程式版本：2026-08-11

本包只更新網頁介面與篩選邏輯，不修改正式 Excel 母檔，也不需要重新上傳 `data/categories`。

## 本版重點

- 先選加工材料，再顯示該材料實際存在的刀型。
- 刀型、加工方式、刀具外徑、刃數及長度採逐層連動。
- 每個下拉選項都由現有刀具資料產生，避免選完得到空白結果。
- B 類加入平銑刀、球刀、圓鼻刀等刀型篩選。
- 搜尋結果依官方系列優先順序，再依刀徑與刀號排列。
- 畫面顯示資料日期與程式版本日期。

## 上傳位置

- `index.html` 上傳到 GitHub 專案最外層，覆蓋舊檔。
- `assets/app.js` 上傳到 GitHub 的 `assets` 資料夾，覆蓋舊檔。
- `assets/app.css` 上傳到 GitHub 的 `assets` 資料夾，覆蓋舊檔。

原本的 `data` 與 `data/categories` 全部保留，不需刪除、不需重傳。
