# WINSTAR V4 雙語選刀與加工參數系統

本版直接沿用 2026-08-10 已完成的正式 Excel 母檔與五大分類 JSON，沒有修改或重建資料母檔。

## 主要功能

- A～E 官方五大分類。
- 刀號欄可跨五類搜尋並自動判斷分類。
- 簡化材質大類與各分類專用加工方式。
- 材質、加工方式及系列連動，只顯示有效組合。
- 繁體中文／English 即時切換。
- 顯示 Vc、進給、RPM、F、Ap、Ae。
- 刀號一鍵複製。
- 依來源 PDF 與頁碼開啟 WINSTAR 官網官方型錄。
- 右上角可前往 WINSTAR 官方網站。

## 發布方式

把本資料夾內全部內容上傳並覆蓋 GitHub Pages 網站根目錄。請勿只上傳 `index.html`；`assets` 與 `data` 也必須一起更新。

本機檢查時請透過網站伺服器開啟，不要直接雙擊 `index.html`，否則瀏覽器可能阻止讀取 JSON。
