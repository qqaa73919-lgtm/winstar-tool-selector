# WINSTAR V4 新版網頁主程式

這是用來替代舊版的 GitHub Pages 發布包，直接沿用 2026-08-10 已完成的正式 Excel 母檔與正式 JSON 資料，不重做、不修改母檔。

## 這版的重點

- 保留 A～E 官方五大分類。
- 保留完整或部分刀號反查。
- 保留系列、材質、加工方式、外徑、刃長與機台最高轉速篩選。
- 搜尋結果先依實體刀號分組。
- 展開刀號後，逐列顯示全部「材質 × 加工方式 × 對應參數」。
- 顯示 Vc、進給、RPM、F、Ap、Ae；設定機台最高轉速後會同步換算 F。

## 使用方式

把本資料夾內全部內容直接上傳，覆蓋原 GitHub Pages 網站根目錄。請勿只上傳 `index.html`，因為程式需要一併讀取 `assets` 與 `data`。

本機檢查時，請透過網站伺服器開啟，不要直接雙擊 `index.html`；直接雙擊會受瀏覽器安全限制而無法讀取 JSON。

JSON 欄位與同刀號多情境規則請參考 `data/JSON_資料結構說明.md`。
