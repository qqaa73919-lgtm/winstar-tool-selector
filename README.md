# WINSTAR 官方選刀系統 V2.9（GitHub 網頁上傳版）

此資料夾只保留 GitHub 網頁上傳所需的 3 個項目：

- `data` 資料夾
- `index.html`
- `README.md`

直接將這 3 個項目全選拖到 GitHub 的 Upload files 頁面，提交後即可設定 GitHub Pages。

官方 PDF 不重複上傳，系統會直接開啟 WINSTAR 原廠 PDF。

## V2.9 重點

- 「依條件選刀」與「刀號反查」已分開。
- 材質與刀徑為必填，其餘為選填。
- AP／AE 只顯示官方目錄實際提供的資料；缺資料時不顯示空白或「不完整」。
- 一般平銑刀、圓鼻銑刀缺少官方 AP 時，會在內部用 `刃長 CL × 0.8` 做安全檢核，但不會顯示成官方 AP。
- 缺少官方 AE 時，只做 `AE ≤ 刀徑 D` 的幾何檢核；有官方 AE 的符合刀具會優先排序。
- 系統每 30 天會自動提醒用電腦檢查 WINSTAR 官方型錄是否更新。
