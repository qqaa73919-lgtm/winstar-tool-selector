# WINSTAR 官方選刀系統 V3.2（GitHub 網頁上傳版）

此資料夾只保留 GitHub 網頁上傳所需的 4 個項目：

- `data` 資料夾
- `index.html`
- `manifest.webmanifest`
- `README.md`

直接將這 4 個項目全選拖到 GitHub 的 Upload files 頁面，提交後 GitHub Pages 會自動發布新版。

官方 PDF 不重複上傳，系統會直接開啟 WINSTAR 原廠 PDF。

## V3.2 重點

- 頁面上方新增五大類共用刀號反查，可輸入完整刀號、部分刀號或系列。
- 整體式銑刀有 5,450 支實際刀號；其他四類另建 3,854 筆官方編碼索引。
- 捨棄式、孔加工、車削與螺紋的條件篩選會優先顯示官方實際編碼。
- 尚未辨識到完整刀號的型錄資料會顯示橘色，只顯示已確認欄位，不自行推測。
- 孔加工使用孔徑與孔深 AP，不出現 AE。
- 螺紋加工的 Pitch／TPI 都是選填。
- 結果只按 1、2、3……排名，不顯示 A／B／C 推薦等級。
- 加工材質會連動常用材料牌號；牌號只作工件記錄，官方未細分時仍依材料大類選刀。
- 加工硬度只在預硬鋼與高硬度鋼時顯示。
- 機台最高轉速位於各類加工需求，刀號反查不需要填寫。
- 加入近期官方產品追蹤與藍白手機主畫面圖示。
- AP／AE 仍只顯示官方實際提供的資料；缺資料時不冒充官方值。
- 已確認的官方 Vc／fz／AP 會換算主軸轉速與進給；缺少官方進給資料時不顯示推測值。
- 預設只顯示全類別反查與五大產品卡，選擇類別後才展開該類表單。
- 系統每 30 天會自動提醒用電腦檢查 WINSTAR 官方型錄是否更新。

## 目前資料完整度

- 整體式銑刀：5,450 支實際刀號與既有官方條件。
- 孔加工、車削、螺紋：已從 WINSTAR 2025 官方型錄抽取可辨識的實際編碼與規格列。
- 捨棄式銑刀：CXLN、CXLO、CXWN 已建立實際刀號；其餘系列先保留官方系列與型錄連結並標示橘色。
