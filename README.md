- 使用者入口：`index.html`
- 電腦管理端：`manager.html`
- 正式分類校正母檔：`docs/WINSTAR_五大類分類校正母檔_V4.2.xlsx`
- PDF 來源與檔案指紋：`docs/PDF_SOURCE_MANIFEST_V4.1.csv`
